# Narrator

> Reads the actual AI responses behind your brand's metrics and tells you whether you're the recommendation, the alternative, or a peer in the list.

Built on the [Peec AI MCP](https://docs.peec.ai/mcp/introduction) for the **#BuiltWithPeec** challenge.

---

## What it is

Narrator is a workflow that introduces a new metric, the **Alternative Index**, and produces two artifacts a marketing team can act on this week:

1. **A live local dashboard** at `http://localhost:8080` with the Alternative Index, evidence quotes from real AI conversations, an AI x topic visibility matrix, an HP-vs-competitor category ownership chart, an interactive citation footprint of your own domain, deep crawl insights, and a one-click pitch template.
2. **A weekly client report** at `http://localhost:8080/report.html` with cover page, table of contents, eight numbered sections, every link clickable, print-to-PDF ready, email-ready HTML.

Same data, two surfaces. The dashboard is for daily monitoring; the report is the artifact you forward to a CMO.

---

## What's in the dashboard

- **Hero with the Alternative Index** - the headline metric, plus directional / validated confidence label and sample size.
- **Evidence: the actual sentences** - real quoted AI responses, classified Primary / Alternative / Alongside / Absent. Each card links to the source chat.
- **Per-AI positioning** - per-engine visibility, sentiment, position, plus the single sharpest narrative observation for each AI.
- **HP visibility by AI x topic** - cross-tab matrix. Click any topic to see the prompts behind it.
- **Category ownership** - HP vs the chosen competitor across topics.
- **Citation footprint on hp.com** - force-directed map of every page on your own domain that AI engines actually retrieve, grouped by section. Filled dots are cited; hollow dots are retrieved-but-not-cited. Click any dot for full per-page metadata.
- **Deep crawl insights** - aggregate stats across the domain. Citation rate by page format, locale performance, retrieved-but-not-cited pages, and topic coverage gaps.
- **Who's telling HP's story** - the editorial and corporate articles authoring the brand's AI narrative. Each tagged Verified (confirmed from chat text) or Inferred (deduced from citation pattern).
- **The one move** - the single highest-leverage action this week, with a copy-send pitch email built in.
- **Methodology** - classification rubric and process, fully documented.

## How it uses Peec's MCP

Tools called by the workflow:

- `list_projects`, `list_brands`, `list_topics`, `list_prompts`, `list_models` - discovery
- `get_brand_report` with `dimensions=[model_id]`, `[topic_id]`, `[model_id, topic_id]` - quantitative metrics, per-engine and per-topic
- `get_domain_report`, `get_url_report` - top citation sources, with `domain` and `mentioned_brand_id` filters
- `list_chats`, `get_chat` - sample assistant responses for sentence-level classification

All visibility, sentiment, position, retrieval and citation numbers in `data.json` are pulled exact from Peec. Framing classifications come from reading the chat text against a 4-class rubric (Primary / Alternative / Alongside / Absent). Sources tagged "Inferred" are honestly flagged when not directly verified from chat text.

## Run locally

Requires Python 3 (for the static file server). No other dependencies.

```bash
python -m http.server 8080 -d dashboard
```

Then open:

- Dashboard: http://localhost:8080
- Weekly report: http://localhost:8080/report.html

Click **Download PDF** on either page for a print-ready export.

---

## Refresh the data from your own Peec account

The dashboard reads from `dashboard/data.json`. To regenerate it against your own brand:

1. Open Claude Code or Claude Desktop in this project directory.
2. Make sure the **Peec AI** MCP connector is enabled.
3. Open `REFRESH.md`, copy the prompt, paste it into a new Claude message.
4. Claude calls the Peec MCP tools, classifies sampled chats, writes a new `dashboard/data.json`.

Refresh `localhost:8080` to see your own brand's data.

## What's next

1. **Adjective ownership** - which descriptors (innovative, reliable, premium) each competitor owns, beyond raw sentiment.
2. **Momentum detection** - once data spans multiple weeks, detect framing drift week-over-week and alert on source-caused shifts.
3. **Citability prediction** - paste a draft URL, get a probability that AI search picks it up for a given prompt cluster.
4. **Slack digest** - same content as the report, posted where marketers actually live.
5. **Multi-brand rollup** - one dashboard view across all brands in a portfolio for agency and holding-company use.
